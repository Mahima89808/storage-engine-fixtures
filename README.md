# storage-engine-fixtures

A centralized engineering repository for exploring relational database architecture, PostgreSQL, SQL, and application-to-database connectivity.

This repository contains SQL experiments, database design fixtures, connectivity examples, and small database-focused implementations.

## 🛠 Tech Stack

* **Database:** PostgreSQL 16+
* **Query Languages:** ANSI SQL & PostgreSQL SQL
* **Python:** `psycopg3`
* **Environment:** Local PostgreSQL & VS Code

## 📁 Repository Structure

```text
storage-engine-fixtures/
│
├── 01_query_writing/     # SQL, schemas, relationships, and query experiments
├── 02_connectivity/      # PostgreSQL connectivity and Python database drivers
└── 03_micro_projects/    # Small database-focused implementations
```

### `01_query_writing`

SQL and relational database fundamentals, including schema design, relationships, constraints, queries, joins, indexing, and PostgreSQL-specific features.

### `02_connectivity`

Application-to-database connectivity using Python and `psycopg3`, covering connection handling, transactions, data mapping, and related database integration patterns.

### `03_micro_projects`

Small implementations that combine database schemas, SQL, and application-level database connectivity.
